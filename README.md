# Анализ продаж интернет-магазина за 2025 год

**Учебный аналитический проект на Python и Pandas** по синтетическим данным интернет-магазина. Цель — изучить продажи, валовую прибыль, ассортимент, каналы привлечения и доставку и предложить проверяемые бизнес-рекомендации.

## Инструменты

Python 3.10+, Pandas 2.0+, NumPy, Matplotlib, SciPy, Jupyter Notebook.

## Задачи и этапы

1. Изучение структуры данных и проверка качества исходной таблицы.
2. Очистка дубликатов, обработка пропусков, некорректных значений и дат.
3. Расчёт выручки, валовой прибыли, рентабельности и среднего чека.
4. Анализ помесячной динамики, категорий и товаров, каналов привлечения, скидок, доставки и повторных покупок.
5. Проверка согласованности расчётов и подготовка рекомендаций.

## Основные результаты

| Показатель | Значение |
| --- | ---: |
| Уникальных заказов после очистки | 1 500 |
| Доставленных заказов | 1 303 |
| Заказов с полными данными для финансового расчёта | 1 237 |
| Рассчитанная выручка | 4 296 544,50 ₽ |
| Валовая прибыль | 1 850 804,50 ₽ |
| Рентабельность по валовой прибыли | 43,08% |
| Средний чек в денежной выборке | 3 473,36 ₽ |

- **Электроника** — лидер по рассчитанной выручке (2 182 414 ₽) и валовой прибыли (780 404 ₽).
- **Органический поиск** — канал с наибольшей рассчитанной выручкой (1 217 833 ₽). Без рекламных расходов нельзя судить об окупаемости каналов.
- **Прямой заход** — доля возвратов 10,00% (24 из 240 вручённых заказов); причины требуют отдельной проверки.
- **Новосибирск** — средний срок доставки 5,25 дня против 3,04 дня в Москве в соответствующих выборках.

## Как запустить

1. Установить Python 3.10+ и библиотеки: `pandas`, `numpy`, `matplotlib`, `scipy`, `jupyter`.
2. Поместить `online_store_orders.csv` в папку `data/` рядом с ноутбуком либо рядом с самим ноутбуком.
3. Открыть `Проект_1.ipynb` в Jupyter и выполнить все ячейки сверху вниз (**Restart Kernel and Run All Cells**).

Рекомендуемая структура:

```text
project1/
├── README.md
├── Проект_1.ipynb
└── data/
    └── online_store_orders.csv
```

**Важно:** CSV-файл необходим для повторного выполнения расчётов. Если его нет в репозитории, ноутбук можно просматривать на GitHub, но запуск потребует отдельного получения данных.

## Ограничения

Данные **синтетические** и охватывают один год. Финансовые показатели рассчитаны не по всем доставленным заказам: для 66 заказов не хватает допустимых значений. Нет данных о рекламных и логистических расходах, поэтому валовую прибыль нельзя трактовать как чистую, а по каналам нельзя оценить ROI. Наблюдаемые связи не доказывают причинно-следственные эффекты.
